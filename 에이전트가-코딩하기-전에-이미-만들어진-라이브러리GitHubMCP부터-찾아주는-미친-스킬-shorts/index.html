코딩 전에 먼저 찾게 하는 스킬

AI(Artificial Intelligence) 에이전트에게 기능을 만들어 달라고 하면, 이미 잘 만들어진 패키지가 있어도 처음부터 코드를 짜는 쪽으로 가기 쉬워요. 영상이 소개하는 search-first는 이 습관을 바꾸는 스킬이에요. 코드를 쓰기 전에 기존 도구부터 찾게 만들어요.

영상은 스킬 문서 첫 화면으로 시작해요. 제목 줄의 노란 부분이 'Research Before You Code'예요. 바로 아래 설명은 이 스킬이 '구현하기 전에 기존 해결책부터 찾는' 흐름을 정리한 것이라고 적어 두었어요.

이 스킬은 ECC라는 저장소에 들어 있어요. ECC는 Claude Code에서 쓰는 스킬과 설정을 모아 둔 저장소예요. 화면 오른쪽 위를 확대하면 Star 숫자가 282k, 곧 약 28만 2천 개예요. 영상은 이걸 '깃허브 별 28만 개'라고 소개해요.

00:15

어디서 찾고, 어떻게 고르나요

스킬을 켜면 정해진 순서대로 움직여요. 처음 하는 일은 바깥이 아니라 내 프로젝트 안을 보는 거예요. 화면의 파일 목록에서 돋보기가 지나가는 줄 하나에만 상자 아이콘과 노란 선이 붙어 있어요. 이미 쓸 만한 코드가 프로젝트에 있으면 그걸 찾았다는 뜻이에요.

프로젝트에 없으면 다섯 곳을 한꺼번에 찾아요. 위쪽 주황색 아이콘에서 선 다섯 개가 뻗어 npm, PyPI, MCP, Skills, GitHub로 이어져요. npm은 자바스크립트 패키지, PyPI는 파이썬 패키지 저장소예요. 코드 라이브러리만이 아니라 MCP 서버와 Claude 스킬까지 같은 자리에 둔 점이 눈에 띄어요.

찾은 후보는 점수로 비교해요. 화면 위쪽 상자 세 개가 후보이고, 왼쪽 다섯 줄이 기준이에요. 기능, 관리, 사용자, 문서, 라이선스 순이에요. 막대가 길수록 그 기준에서 점수가 높아요. 영상은 이를 '기능, 관리 상태, 사용자 수, 문서, 라이선스로 점수를 매긴다'고 설명해요.

점수를 본 뒤에는 셋 중 하나로 정해요. 화면에서 Adopt 칸에는 체크 표시가, Extend 칸에는 상자를 파란 테두리로 감싼 그림이, Build 칸에는 코드 기호가 있어요. 감싼 그림이 '설치한 뒤 얇게 감싼다'는 뜻을 그대로 보여 줘요.

선택언제무엇을 하나요
Adopt후보가 딱 맞을 때그대로 설치해서 써요
Extend비슷하지만 조금 모자랄 때설치한 뒤 얇게 감싸서 맞춰요
Build정말 쓸 만한 게 없을 때그때만 직접 짜요

지금까지의 화면을 한 흐름으로 이으면 이렇게 돼요. 프로젝트 확인부터 결정까지, 직접 짜는 길은 맨 끝 한 갈래뿐이에요.

예시와 쓰는 법

영상은 예시 하나를 보여 줘요. 마크다운 문서에 깨진 링크가 있는지 검사하는 기능이에요. 화면의 다섯 줄을 위에서부터 읽으면 앞에서 본 흐름과 같아요.

  • Need — 마크다운 파일의 깨진 링크를 검사해야 해요.
  • Search — npm에서 'markdown dead link checker'로 찾아요.
  • Found — textlint-rule-no-dead-link가 9/10점이에요.
  • Action — 'ADOPT', 곧 npm install textlint-rule-no-dead-link 한 줄로 설치해요.
  • Result — 직접 짠 코드는 0줄이에요.
영상에 없는 보충 설명

스킬 원문(SKILL.md)은 영상보다 조금 더 자세해요. 결정 표에는 네 번째 선택지 Compose가 있어요. 쓸 만한 후보가 여럿인데 하나하나는 약할 때, 작은 패키지 2~3개를 조합하는 방법이에요. 점수 기준에도 영상의 다섯 가지 외에 의존성(deps)이 더 들어 있어요.

스킬 문서에는 예시가 두 개 더 있어요. HTTP(HyperText Transfer Protocol) 클라이언트(got, httpx)를 그대로 쓰는 예와, ajv-cli를 설치하고 프로젝트용 스키마만 쓰는 Adopt + Extend 예예요. 앞의 깨진 링크 예시에 나온 textlint-rule-no-dead-link는 지금도 npm에 있는 패키지예요.

쓰는 법은 두 단계예요. 화면의 Claude Code 창을 보면 첫 줄 'ECC 플러그인 설치해 줘'에 체크가 붙어 있어요. 그 아래 '서치 퍼스트로 먼저 찾아봐'를 입력하자 /search-first가 실행돼요. 기능을 맡기기 전에 이 한마디만 붙이면 된다는 뜻이에요.

영상에 없는 보충 설명

저장소 주소는 지금 github.com/affaan-m/ECC예요. 예전 주소 everything-claude-code로 들어가도 이 주소로 넘어가요. README가 안내하는 Claude Code 설치 명령은 아래 두 줄이에요.

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

설치한 뒤 새 세션에서 /plugin list로 ecc@ecc가 켜져 있는지 확인하라고 적혀 있어요.
