별 많은 스킬도 몰래 설치를 시켜요

발표자는 직접 겪은 일로 시작해요. GitHub 스타가 18,825개 달린 인기 스킬을 깔아 썼는데, 그 스킬이 사용자가 시키지 않은 설치를 실행했다고 해요. 별 개수는 많은 사람이 좋아한다는 표시일 뿐, 스킬이 내 컴퓨터에서 무엇을 하는지는 알려 주지 않아요.

아래 화면 위쪽이 그 스킬의 별 개수예요. 아래 터미널 창을 보면 스킬 실행 중에 '다운로드 실패…'가 뜨자 곧바로 pip install -U yt-dlp가 실행되고, yt-dlp 2026.03.17로 버전이 바뀌어요. 빨간 딱지에 적힌 대로 '안 시킨 설치'예요.

자막에는 '별 1만 8천 개'라고 나오지만 화면 숫자는 18,825개예요. 이 문서는 화면 숫자를 따랐어요.

깔기 전 점검표 세 가지

영상은 '스킬 깔기 전 점검표'를 한 줄씩 채우며 설명해요. 세 질문을 먼저 표로 모으면 이래요. 가운데 칸은 화면에서 각 질문 밑에 작게 적힌 단서예요.

하나, 내 키 파일을 읽나요?

아래 화면 왼쪽은 내 폴더 속 .env 파일이에요. 안에 OPENAI_KEY, GEMINI_KEY 같은 API 키가 적혀 있어요. 오른쪽에는 그 열쇠가 OpenAI, Gemini 같은 다른 AI 서비스로 넘어가고, 아래 '내 지갑'에서 동전이 빠져나가요. 빨간 칸에 적힌 대로 '요금은 내 키로' 나가는 구조예요.

둘, 설치나 업데이트를 시키나요?

두 번째 줄 밑에는 pip · npm · curl이 적혀 있어요. 모두 인터넷에서 무언가를 내려받거나 까는 명령이에요. 아래 화면 오른쪽의 '설명서 한 줄 "업데이트하세요"'가 핵심이에요. 스킬 설명서에 이 한 줄만 있어도 상자(패키지)가 열리며 설치가 진행돼요. 발표자는 이게 자기가 당한 경우라고 강조해요.

셋, 내 자료를 밖으로 보내나요?

마지막 줄은 '외부 전송'이에요. 아래 화면처럼 '내 컴퓨터'의 문서가 점선을 따라 '외부 서버'로 날아가는 경우예요. 이 화면에서 점검표 세 줄이 모두 채워져요.

영상에 없는 보충 설명

영상은 어디를 열어 확인할지까지는 말하지 않아요. Claude Code 공식 문서를 보면 스킬은 SKILL.md 머리말의 allowed-tools로 자기가 실행되는 동안 일부 도구를 묻지 않고 쓰도록 미리 허용할 수 있어요. 문서도 스킬이 스스로 넓은 도구 권한을 줄 수 있으니 저장소에 든 스킬은 allowed-tools를 먼저 살펴보라고 해요. SKILL.md 본문과 함께 딸린 스크립트에서 .env, pip, npm, curl 같은 단어를 찾아보면 위 세 질문에 빨리 답할 수 있어요.

처음 쓰는 스킬은 '매번 묻기'로

마지막 조언은 권한 모드예요. 아래 화면에는 '매번 묻기', '편집만 자동 허용', '전부 자동 허용' 세 가지 선택지가 있어요. 오른쪽 위 '처음 쓰는 스킬' 딱지가 붙은 채로 '매번 묻기'에 표시가 들어가고, '전부 자동 허용'에는 빨간 X가 쳐져 있어요.

앞의 점검표가 깔기 전 확인이라면, 권한 모드는 쓰는 동안의 안전장치예요. 점검에서 놓친 행동이 있어도 실행 직전에 한 번 더 걸러져요.

영상에 없는 보충 설명

화면의 세 선택지는 Claude Code 권한 모드와 이렇게 대응한다고 볼 수 있어요. '매번 묻기'는 도구를 처음 쓸 때마다 묻는 default(화면에는 Manual로 표시), '편집만 자동 허용'은 작업 폴더 안 파일 수정을 자동으로 받아 주는 acceptEdits, '전부 자동 허용'은 확인 창을 건너뛰는 bypassPermissions예요. 공식 문서는 bypassPermissions를 컨테이너나 VM(Virtual Machine)처럼 망가져도 괜찮은 격리 환경에서만 쓰라고 경고해요. 이 밖에 plan, auto 모드도 있어요.
