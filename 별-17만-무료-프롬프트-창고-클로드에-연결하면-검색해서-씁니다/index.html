prompts.chat은 어떤 창고인가요

요리할 때 레시피를 매번 새로 짜지 않고 앱에서 찾아 따라 하잖아요. 영상은 프롬프트도 똑같다고 봐요. 이미 잘 만들어진 걸 찾아 쓰면 되고, 그 레시피 앱 역할을 하는 게 prompts.chat이에요.

아래 화면 왼쪽 위 카드가 깃허브 저장소 f/prompts.chat이에요. 별이 175,862개(카드 오른쪽 위에 11/5 기준이라고 적혀 있어요)이고, 옆에 옛 이름 Awesome ChatGPT Prompts가 붙어 있어요. 가운데 선반의 숫자 2,897개는 저장소의 prompts.csv 파일 하나에 든 프롬프트 수예요.

다음 화면은 상자에 붙은 CC0(Creative Commons Zero) 도장을 보여 줘요. 도장 아래 작은 글씨가 '퍼블릭 도메인'이에요. 그래서 영상은 공짜로 고쳐 써도 된다고 해요.

다만 영상의 요점은 이 창고를 사람이 직접 뒤지는 게 아니에요. 클로드에 창고를 붙여서 클로드가 대신 검색하게 하는 거예요.

영상에 없는 보충 설명

2026년 11월 12일에 저장소를 다시 봤더니 별은 176,922개, prompts.csv는 2,956줄(머리글 제외)로 조금 늘어 있었어요. 라이선스는 둘로 나뉘어요. 프롬프트 내용(prompts.csv, PROMPTS.md, 사용자가 올린 프롬프트)은 CC0 1.0이고, 사이트 소스 코드는 MIT(Massachusetts Institute of Technology)예요.

클로드 앱에 주소 한 줄로 연결하기

연결은 클로드 앱의 커넥터 메뉴에서 해요. Customize > Connectors로 들어가 '직접 추가'를 누르면 Add custom connector 창이 떠요. 아래 화면처럼 Name 칸에 prompts.chat, URL(Uniform Resource Locator) 칸에 주소 한 줄을 넣고 오른쪽 아래 Add를 누르면 끝이에요.

칸넣을 값
Nameprompts.chat
URLhttps://prompts.chat/api/mcp

이 창고는 가입도 API 키도 받지 않아요. 아래 화면 가운데 줄의 인증 설정이 No sign in이에요. 그 아래 Free 칸은 무료 요금제에서 사용자 지정 커넥터를 1개까지 쓸 수 있고, 그 한 자리에 prompts.chat이 들어간다는 뜻이에요.

앱에서 한 번 붙이면 클로드 코드 탭에서도 그대로 써요. 아래 화면은 Claude Code에서 /mcp를 열었을 때 prompts.chat이 claude.ai 꼬리표를 달고 목록에 뜬 모습이에요.

영상에 없는 보충 설명

Anthropic 도움말도 무료 사용자는 사용자 지정 커넥터를 1개까지 쓸 수 있다고 적고 있어요. 클로드 코드 문서에 따르면 claude.ai 계정으로 로그인한 경우에만 앱의 커넥터가 자동으로 넘어와요. API 키(ANTHROPIC_API_KEY)나 Bedrock 같은 다른 제공자로 쓰고 있다면 넘어오지 않아요. 그럴 땐 터미널에서 직접 추가하면 돼요.

claude mcp add --transport http prompts.chat https://prompts.chat/api/mcp

prompts.chat 문서는 검색 같은 대부분의 기능은 인증 없이 되고, MCP(Model Context Protocol)로 프롬프트를 저장하거나 내 비공개 프롬프트를 볼 때만 pchat_로 시작하는 API 키가 필요하다고 해요. 검색 도구 이름은 search_prompts, 꺼내 오는 도구는 get_prompt예요.

찾기와 고치기를 한 문장으로

영상은 찾은 프롬프트를 그대로 쓰면 반만 쓰는 거라고 해요. 아래 화면 왼쪽 카드에 'EN' 표시가 붙은 Advertiser(광고 담당자) 프롬프트가 있어요. 카드 아래 '남의 상황' 꼬리표, 오른쪽 '우리 가게'와의 사이에 그은 빨간 X가 두 가지 문제를 보여 줘요. 대부분 영어이고, 남의 상황에 맞춰 쓰여 있다는 거예요.

그래서 영상 처음에 약속한 '연결하자마자 시킬 문장'이 이거예요. 화면 속 클로드 입력창에 그대로 적혀 있어요.

창고에서 광고 문구 프롬프트 찾아서 한국어로 우리 가게에 맞게 고쳐서 써줘.
